# 🛡️ Nexus-Guard

## AI-Driven Network Intrusion Detection & Prevention System

Nexus-Guard is a terminal-based network security project designed to monitor network traffic, analyze suspicious activity, and eventually respond to potential threats.

This project is being built as a long-term learning project covering networking, cybersecurity, machine learning, Linux systems, concurrency, and DevOps.

---

## Project Status

Current Phase:

- Phase 0 — Foundation & Mini Projects
- Current Project: Network Ping Sweeper
